# Understanding LLM Call Sites in Agentic Systems

Supplementary material for an anonymous submission under double-anonymous review.

- `index.html`: the project website (open it in a browser, or use the website view of this repository).
- `assets/fig/`: the figures of the paper.

The replication package contains the 40 subject systems and their commits, all call sites, outputs and consumption edges, the expected and implemented contracts with verdicts and source evidence, the review records, and the analysis scripts.
